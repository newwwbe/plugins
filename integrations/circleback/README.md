# Circleback

Search meetings, transcripts, action items, and emails.

## Install

```
/plugin install circleback@newwwbe
```

Or from a terminal: `claude plugin install circleback@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `circleback`: `https://circleback.ai/api/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
