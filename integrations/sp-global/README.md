# S&P Global

Query S&P Capital IQ financials, prices, and transcripts.

## Install

```
/plugin install sp-global@newwwbe
```

Or from a terminal: `claude plugin install sp-global@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `sp-global`: `https://kfinance.kensho.com/integrations/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
