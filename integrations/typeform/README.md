# Typeform

Build forms, analyze responses, and manage contacts.

## Install

```
/plugin install typeform@newwwbe
```

Or from a terminal: `claude plugin install typeform@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `typeform`: `https://api.typeform.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
