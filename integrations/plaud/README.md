# Plaud

Work with your Plaud recordings: list and search meetings and voice notes, read full transcripts with speaker labels, and pull AI summaries, action items, and key topics into your workflow.

## Install

```
/plugin install plaud@newwwbe
```

Or from a terminal: `claude plugin install plaud@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `plaud`: `https://mcp.plaud.ai/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
