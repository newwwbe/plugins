# Calendly

Check availability and book, cancel, or reschedule.

## Install

```
/plugin install calendly@newwwbe
```

Or from a terminal: `claude plugin install calendly@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `calendly`: `https://mcp.calendly.com/` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
