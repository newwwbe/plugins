# etoro

View your eToro portfolio, balances, positions, and watchlists, research instruments and traders, and prepare and place trades.

## Install

```
/plugin install etoro-trading@newwwbe
```

Or from a terminal: `claude plugin install etoro-trading@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `etoro-trading`: `https://mcp.public-api.etoro.com` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
