# Webull

View accounts, positions, orders, watchlists, and market data.

## Install

```
/plugin install webull@newwwbe
```

Or from a terminal: `claude plugin install webull@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `webull`: `https://api.webull.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
