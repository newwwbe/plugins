# Clay

Enrich people and companies, run AI research agents.

## Install

```
/plugin install clay@newwwbe
```

Or from a terminal: `claude plugin install clay@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `clay`: `https://api.clay.com/v3/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
