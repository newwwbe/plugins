# Greenhouse

Search candidates, jobs, and applications, and review scorecards in Greenhouse Recruiting.

## Install

```
/plugin install greenhouse@newwwbe
```

Or from a terminal: `claude plugin install greenhouse@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `greenhouse`: `https://mcp.us.greenhouse.io/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
