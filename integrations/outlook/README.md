# Outlook

Search, read, and send Microsoft Outlook email, and look up contacts.

## Install

```
/plugin install outlook@newwwbe
```

Or from a terminal: `claude plugin install outlook@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `outlook`: `https://api.cursor.com/rest-mcp/outlook/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
