# Profound

Track AI visibility, sentiment, and citations.

## Install

```
/plugin install profound@newwwbe
```

Or from a terminal: `claude plugin install profound@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `profound`: `https://mcp.tryprofound.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
