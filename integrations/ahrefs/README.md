# Ahrefs

Research keywords, backlinks, rankings, and site health.

## Install

```
/plugin install ahrefs@newwwbe
```

Or from a terminal: `claude plugin install ahrefs@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `ahrefs`: `https://api.ahrefs.com/mcp/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
