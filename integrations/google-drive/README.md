# Google Drive

Search, read, create, and share files.

## Install

```
/plugin install google-drive@newwwbe
```

Or from a terminal: `claude plugin install google-drive@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `google-drive`: `https://api.cursor.com/rest-mcp/google-drive/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.

## Skills

- `/google-drive:google-drive`
