# Google Cloud BigQuery

Explore datasets and tables and run SQL queries.

## Install

```
/plugin install google-cloud-bigquery@newwwbe
```

Or from a terminal: `claude plugin install google-cloud-bigquery@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `google-cloud-bigquery`: `https://bigquery.googleapis.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
