# Hunter

Find and verify emails, discover companies, and save leads.

## Install

```
/plugin install hunter@newwwbe
```

Or from a terminal: `claude plugin install hunter@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `hunter`: `https://mcp.hunter.io/mcp` (API key/token)

Run `/mcp` in Claude Code to check the connection or to sign in.

## Configuration

Set these with `claude plugin configure hunter`:

- `HUNTER_API_KEY` (required): API key from https://hunter.io/api-keys. The Free plan works.
