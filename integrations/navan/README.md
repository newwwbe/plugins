# Navan

Query expenses, travel bookings, policies, and cards.

## Install

```
/plugin install navan@newwwbe
```

Or from a terminal: `claude plugin install navan@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `navan`: `https://mcp.navan.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
