# X Money

Use your X Money Card, send money to users on X, manage your finances, view your balance and browse through your transaction history.

## Install

```
/plugin install x-money@newwwbe
```

Or from a terminal: `claude plugin install x-money@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `x-money`: `https://mcp.money.x.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.

## Skills

- `/x-money:x-money-guide`
