# Otter.ai

Search meeting history and pull full transcripts.

## Install

```
/plugin install otter@newwwbe
```

Or from a terminal: `claude plugin install otter@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `otter`: `https://mcp.otter.ai/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
