# Daloopa

Pull source-linked fundamentals, KPIs, filings, and prices.

## Install

```
/plugin install daloopa@newwwbe
```

Or from a terminal: `claude plugin install daloopa@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `daloopa`: `https://mcp.daloopa.com/server/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
