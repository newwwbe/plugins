# Square

Work with payments, orders, catalog, customers, and invoices.

## Install

```
/plugin install square@newwwbe
```

Or from a terminal: `claude plugin install square@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `square`: `https://mcp.squareup.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
