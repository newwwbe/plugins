# OneDrive

Browse, search, and read Microsoft OneDrive files.

## Install

```
/plugin install onedrive@newwwbe
```

Or from a terminal: `claude plugin install onedrive@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `onedrive`: `https://api.cursor.com/rest-mcp/onedrive/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
