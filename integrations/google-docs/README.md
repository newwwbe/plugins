# Google Docs

Read, create, and edit documents.

## Install

```
/plugin install google-docs@newwwbe
```

Or from a terminal: `claude plugin install google-docs@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `google-docs`: `https://api.cursor.com/rest-mcp/google-docs/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.

## Skills

- `/google-docs:google-docs`
