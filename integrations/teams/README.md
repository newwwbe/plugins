# Teams

Search, read, and send Microsoft Teams chats and channel messages.

## Install

```
/plugin install teams@newwwbe
```

Or from a terminal: `claude plugin install teams@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `teams`: `https://api.cursor.com/rest-mcp/teams/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
