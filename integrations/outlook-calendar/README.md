# Outlook Calendar

List, create, update, and cancel Microsoft Outlook calendar events.

## Install

```
/plugin install outlook-calendar@newwwbe
```

Or from a terminal: `claude plugin install outlook-calendar@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `outlook-calendar`: `https://api.cursor.com/rest-mcp/outlook-calendar/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
