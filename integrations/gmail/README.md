# Gmail

Search, read, draft, and manage email.

## Install

```
/plugin install gmail@newwwbe
```

Or from a terminal: `claude plugin install gmail@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `gmail`: `https://gmailmcp.googleapis.com/mcp/v1` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
