# Attio

Search and update CRM records, lists, notes, and tasks.

## Install

```
/plugin install attio@newwwbe
```

Or from a terminal: `claude plugin install attio@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `attio`: `https://mcp.attio.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
