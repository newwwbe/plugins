# Gamma

Generate presentations, documents, and webpages.

## Install

```
/plugin install gamma@newwwbe
```

Or from a terminal: `claude plugin install gamma@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `gamma`: `https://mcp.gamma.app/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
