# Customer.io

Build campaigns, manage segments, and query people.

## Install

```
/plugin install customer-io@newwwbe
```

Or from a terminal: `claude plugin install customer-io@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `customer-io`: `https://mcp.customer.io/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
