# Similarweb

Analyze website traffic, audiences, and competitors.

## Install

```
/plugin install similarweb@newwwbe
```

Or from a terminal: `claude plugin install similarweb@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `similarweb`: `https://mcp.similarweb.com` (API key/token)

Run `/mcp` in Claude Code to check the connection or to sign in.

## Configuration

Set these with `claude plugin configure similarweb`:

- `SIMILARWEB_API_KEY` (required): REST API key from Similarweb under Account Settings → Data Tools → REST API.
