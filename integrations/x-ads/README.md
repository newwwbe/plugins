# X Ads

Manage ad campaigns, create ads, track conversions, and pull performance stats.

## Install

```
/plugin install x-ads@newwwbe
```

Or from a terminal: `claude plugin install x-ads@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `x-ads`: `https://ads-api.x.com/mcp` (OAuth sign-in)

Run `/mcp` in Claude Code to check the connection or to sign in.
