# Finary

Read your net worth, accounts, holdings, spending, and budgets.

## Install

```
/plugin install finary@newwwbe
```

Or from a terminal: `claude plugin install finary@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `finary`: `https://public-api.finary.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
