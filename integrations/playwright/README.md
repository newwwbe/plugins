# Playwright

Navigate, click, screenshot, and test in a real browser.

## Install

```
/plugin install playwright@newwwbe
```

Or from a terminal: `claude plugin install playwright@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `playwright`: `npx -y @playwright/mcp@latest` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
