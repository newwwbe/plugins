# Buffer

Manage social media with Buffer: draft, schedule, and publish posts across connected channels, manage the queue and ideas, and review post performance.

## Install

```
/plugin install buffer@newwwbe
```

Or from a terminal: `claude plugin install buffer@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `buffer`: `https://mcp.buffer.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
