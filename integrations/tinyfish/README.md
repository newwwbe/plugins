# TinyFish

Browse and automate the web with TinyFish: run multi-step web automations, search the web, extract clean page content, and drive remote stealth browser sessions.

## Install

```
/plugin install tinyfish@newwwbe
```

Or from a terminal: `claude plugin install tinyfish@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `tinyfish`: `https://agent.tinyfish.ai/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
