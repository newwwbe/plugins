# Craft

Search, create, and update documents and daily notes.

## Install

```
/plugin install craft@newwwbe
```

Or from a terminal: `claude plugin install craft@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `craft`: `https://mcp.craft.do/my/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
