# Workable

Search candidates, move pipelines, and manage HR records.

## Install

```
/plugin install workable@newwwbe
```

Or from a terminal: `claude plugin install workable@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `workable`: `https://mcp.workable.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
