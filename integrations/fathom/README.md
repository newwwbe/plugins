# Fathom

Search meetings and pull transcripts and summaries.

## Install

```
/plugin install fathom@newwwbe
```

Or from a terminal: `claude plugin install fathom@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `fathom`: `https://api.fathom.ai/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
