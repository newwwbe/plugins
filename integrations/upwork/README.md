# Upwork

Search talent, post jobs, and manage contracts.

## Install

```
/plugin install upwork@newwwbe
```

Or from a terminal: `claude plugin install upwork@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `upwork`: `https://mcp.upwork.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
