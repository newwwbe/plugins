# Fireflies

Search meeting transcripts, summaries, and action items.

## Install

```
/plugin install fireflies@newwwbe
```

Or from a terminal: `claude plugin install fireflies@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `fireflies`: `https://api.fireflies.ai/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
