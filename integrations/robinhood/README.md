# Robinhood

View portfolios, positions, orders, watchlists, and market data, and trade in a Robinhood Agentic account.

## Install

```
/plugin install robinhood@newwwbe
```

Or from a terminal: `claude plugin install robinhood@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `robinhood`: `https://agent.robinhood.com/mcp/trading` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
