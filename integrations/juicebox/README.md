# Juicebox

Query recruiting analytics, shortlists, and sourcing agents.

## Install

```
/plugin install juicebox@newwwbe
```

Or from a terminal: `claude plugin install juicebox@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `juicebox`: `https://mcp.juicebox.ai/v1` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
