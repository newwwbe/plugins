# GoDaddy

Brainstorm domain names and check availability.

## Install

```
/plugin install godaddy@newwwbe
```

Or from a terminal: `claude plugin install godaddy@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `godaddy`: `https://api.godaddy.com/v1/domains/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
