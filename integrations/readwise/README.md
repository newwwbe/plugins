# Readwise

Search highlights and Reader documents, save articles.

## Install

```
/plugin install readwise@newwwbe
```

Or from a terminal: `claude plugin install readwise@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `readwise`: `https://mcp2.readwise.io/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
