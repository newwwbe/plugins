# SharePoint

Search and read Microsoft SharePoint sites, document libraries, files, and lists.

## Install

```
/plugin install sharepoint@newwwbe
```

Or from a terminal: `claude plugin install sharepoint@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `sharepoint`: `https://api.cursor.com/rest-mcp/sharepoint/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
