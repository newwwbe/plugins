# Guru

Search company knowledge and draft verified answers.

## Install

```
/plugin install guru@newwwbe
```

Or from a terminal: `claude plugin install guru@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `guru`: `https://mcp.api.getguru.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
