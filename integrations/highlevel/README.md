# HighLevel

Work with contacts, conversations, opportunities, calendars, and payments.

## Install

```
/plugin install highlevel@newwwbe
```

Or from a terminal: `claude plugin install highlevel@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `highlevel`: `https://services.leadconnectorhq.com/mcp/cursor/v2` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
