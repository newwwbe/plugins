# Semrush

Research keywords, backlinks, traffic, and competitors.

## Install

```
/plugin install semrush@newwwbe
```

Or from a terminal: `claude plugin install semrush@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `semrush`: `https://mcp.semrush.com/v2/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
