# X

Search posts, read timelines, pull trends, manage bookmarks, and access X Chat.

## Install

```
/plugin install x@newwwbe
```

Or from a terminal: `claude plugin install x@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `x`: `https://api.x.com/mcp` (OAuth sign-in)

Run `/mcp` in Claude Code to check the connection or to sign in.
