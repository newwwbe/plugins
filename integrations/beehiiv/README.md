# beehiiv

Run your beehiiv newsletter from chat: draft and edit posts, organize subscribers with tags, custom fields, and segments, build automations, and review publication, post, and website performance.

## Install

```
/plugin install beehiiv@newwwbe
```

Or from a terminal: `claude plugin install beehiiv@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `beehiiv`: `https://mcp.beehiiv.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
