# Klaviyo

Manage profiles, segments, campaigns, and flows.

## Install

```
/plugin install klaviyo@newwwbe
```

Or from a terminal: `claude plugin install klaviyo@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `klaviyo`: `https://mcp.klaviyo.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
