# Ashby

Search candidates, prep interviews, and manage pipeline tasks.

## Install

```
/plugin install ashby@newwwbe
```

Or from a terminal: `claude plugin install ashby@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `ashby`: `https://mcp.ashbyhq.com/mcp/v1` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
