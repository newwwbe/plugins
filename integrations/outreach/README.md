# Outreach

Search sequences, prospects, and Kaia meetings.

## Install

```
/plugin install outreach@newwwbe
```

Or from a terminal: `claude plugin install outreach@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `outreach`: `https://api.outreach.io/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
