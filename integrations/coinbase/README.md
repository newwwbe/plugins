# Coinbase

Check balances, get quotes, and preview or place trades.

## Install

```
/plugin install coinbase@newwwbe
```

Or from a terminal: `claude plugin install coinbase@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `coinbase`: `https://agents.coinbase.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
