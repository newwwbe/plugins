# Amplemarket

Search people and companies, enrich leads, run sequences.

## Install

```
/plugin install amplemarket@newwwbe
```

Or from a terminal: `claude plugin install amplemarket@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `amplemarket`: `https://mcp.amplemarket.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
