# Mem

Capture, search, and organize notes and collections.

## Install

```
/plugin install mem@newwwbe
```

Or from a terminal: `claude plugin install mem@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `mem`: `https://mcp.mem.ai/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
