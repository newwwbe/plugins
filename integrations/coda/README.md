# Coda

Search docs, read pages, and update tables.

## Install

```
/plugin install coda@newwwbe
```

Or from a terminal: `claude plugin install coda@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `coda`: `https://docs.superhuman.com/apis/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
