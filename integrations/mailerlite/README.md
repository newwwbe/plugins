# MailerLite

Manage subscribers, groups, campaigns, and automations.

## Install

```
/plugin install mailerlite@newwwbe
```

Or from a terminal: `claude plugin install mailerlite@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `mailerlite`: `https://mcp.mailerlite.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
