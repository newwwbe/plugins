# Statsig

Inspect and manage feature gates, experiments, dynamic configs, and metrics.

## Install

```
/plugin install statsig@newwwbe
```

Or from a terminal: `claude plugin install statsig@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `statsig`: `https://api.statsig.com/v3/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
