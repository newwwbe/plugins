# Interactive Brokers

Review positions, balances, P&L, and draft trade instructions.

## Install

```
/plugin install interactive-brokers@newwwbe
```

Or from a terminal: `claude plugin install interactive-brokers@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `interactive-brokers`: `https://api.ibkr.com/v1/api/mcp-public` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
