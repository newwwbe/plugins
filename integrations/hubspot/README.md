# HubSpot

Search and update contacts, companies, deals, and tickets.

## Install

```
/plugin install hubspot@newwwbe
```

Or from a terminal: `claude plugin install hubspot@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `hubspot`: `https://mcp.hubspot.com` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
