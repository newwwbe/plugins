# Google Slides

Create, edit, and render presentations.

## Install

```
/plugin install google-slides@newwwbe
```

Or from a terminal: `claude plugin install google-slides@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `google-slides`: `https://api.cursor.com/rest-mcp/google-slides/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.

## Skills

- `/google-slides:google-slides`
