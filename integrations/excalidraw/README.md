# Excalidraw

Draw and export hand-drawn diagrams from chat.

## Install

```
/plugin install excalidraw@newwwbe
```

Or from a terminal: `claude plugin install excalidraw@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `excalidraw`: `https://mcp.excalidraw.com/mcp` (API key/token)

Run `/mcp` in Claude Code to check the connection or to sign in.
