# Jotform

Create and edit forms, then read submissions.

## Install

```
/plugin install jotform@newwwbe
```

Or from a terminal: `claude plugin install jotform@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `jotform`: `https://mcp.jotform.com` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
