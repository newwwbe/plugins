# Intercom

Search conversations, contacts, and Help Center articles.

## Install

```
/plugin install intercom@newwwbe
```

Or from a terminal: `claude plugin install intercom@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `intercom`: `https://mcp.intercom.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
