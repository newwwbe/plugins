# Todoist

Create, find, and complete tasks and projects.

## Install

```
/plugin install todoist@newwwbe
```

Or from a terminal: `claude plugin install todoist@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `todoist`: `https://ai.todoist.net/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
