# Brex

Query expenses, receipts, bills, cards, and travel.

## Install

```
/plugin install brex@newwwbe
```

Or from a terminal: `claude plugin install brex@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `brex`: `https://api.brex.com/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
