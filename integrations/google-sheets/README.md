# Google Sheets

Read, write, and append spreadsheet data.

## Install

```
/plugin install google-sheets@newwwbe
```

Or from a terminal: `claude plugin install google-sheets@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `google-sheets`: `https://api.cursor.com/rest-mcp/google-sheets/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.

## Skills

- `/google-sheets:google-sheets`
