# Meltwater

Search media and social mentions and pull analytics.

## Install

```
/plugin install meltwater@newwwbe
```

Or from a terminal: `claude plugin install meltwater@newwwbe` (after `claude plugin marketplace add newwwbe/plugins`).

## MCP server

- `meltwater`: `https://api.meltwater.com/v2/mcp` (sign-in when the server asks)

Run `/mcp` in Claude Code to check the connection or to sign in.
